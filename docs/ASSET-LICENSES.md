# Asset licenses and provenance

This foundation pass uses runtime-generated Godot primitive geometry and no imported production art or audio.

Future workflow:

- Scenario: 2D concepts, visual assets, and textures.
- Blender: 3D modeling, cleanup, rigging, and environment assets.
- Godot: materials, lighting, integration, and gameplay.

Every external asset must record source, creator, license/permission, import date, and any attribution requirements here before it is committed. Do not download or commit copyrighted Voidcaller masters without explicit authorization.

Current missing production assets: authorized Voidcaller audio, final models, textures, materials, VFX, UI art, and animation.
